Good Practices Challenge

¡Bienvenido al repositorio de Buenas Prácticas de Programación!
Aquí encontrarás ejemplos en Java, Python, C++ y JavaScript diseñados con errores intencionales para que los corrijas aplicando principios fundamentales de desarrollo limpio.

¿Qué debes hacer?
Explora los ejemplos in main/ (especialmente los que son en Java)
  
- Ve a **Issues** y selecciona el reto que vas a resolver. Cada Issue contiene:

El código base con problemas.
Pistas en el title para guiar tu refactorización.

Tu misión

Aplica KISS: Mantén el código simple y fácil de entender.
Aplica DRY: Elimina duplicación, reutiliza funciones comunes.
Aplica SOLID (SRP): Cada método debe tener una sola responsabilidad y devolver valores en lugar de mezclar lógica con presentación.

Cómo participar!

Elige un Issue y lee el código base.
Refactoriza el código aplicando las buenas prácticas.
Crea un Pull Request con tu solución y menciona el Issue (ejemplo: Fixes #3).
¡Revisa el resultado y aprende cómo mejorar tu código!

Pasos:
-Comprobar tener git con git --version
-Si no existe, instalar y crear usuario.
-Una vez en CMD en el cd de destino..
-Acceder al repositorio localmente.(git clone https://github.com/<TU-USUARIO>/Good_Practices.git)
- Crear la carpeta `Equipo X/` en la raíz (si no existe). (git checkout main , mkdir -p Equipo X)
- Guardar tu archivo corregido dentro de `Equipo X/`. 
- Hacer `git add`, `commit` y `push` para subir tu solución.(git add EqipoX/) (
git commit -m "Solución en EquipoX/ aplicando KISS/DRY/SRP — Fixes #<del Issue>") 
(git push origin main).
